# AI-Faces by Illinois

**A database of 1,152 photorealistic, AI-generated images depicting children for use in psychological research.**

Developed at the University of Illinois Urbana-Champaign, AI-Faces by Illinois provides systematically varied child-face stimuli accompanied by adult norming ratings. This repository provides an additional distribution location for the image collection originally shared on [OSF](https://osf.io/vurm5/).

**Associated article:** [AI-Faces by Illinois: A database of AI-generated faces depicting children](https://doi.org/10.3758/s13428-026-03182-y), *Behavior Research Methods*.

## Image collection

The database includes images varying across the following prompted characteristics:

| Dimension | Categories |
| --- | --- |
| Age | 3, 6, 10, and 15 years |
| Gender | Boys and girls |
| Race/ethnicity | Black, East Asian, Latine, Middle Eastern/North African, Native American, Pacific Islander, South Asian, and White |
| Emotional expression | Smiling, angry, and frowning |

Each age × gender × race/ethnicity combination contains 18 images: 10 smiling, 4 angry, and 4 frowning, yielding 1,152 images in total.

Images were generated and processed to standardize facial orientation, gaze direction, clothing, and background while retaining variation in appearance within groups.

These stimuli are AI-generated images, not photographs of actual children. Demographic labels describe the intended depictions specified during image generation. Researchers should consult the norming ratings when selecting stimuli because prompted characteristics and observers' perceptions may differ.

## Download the images

Visit the [Releases page](https://github.com/AI-Face-By-Illinois/ai-face-by-illinois.github.io/releases) for image archives as they become available. The original collection is also available on [OSF](https://osf.io/vurm5/).

To download a GitHub release:

1. Open the release and expand **Assets**.
2. Download the attached image ZIP archive or archives. If the collection is divided across multiple archives, download all parts for the complete collection.
3. Extract the files, preserving their original filenames and folder structure so that images can be matched to the norming datasheet.

Use the explicitly named image archives. GitHub's automatically generated **Source code (zip)** and **Source code (tar.gz)** downloads do not include separately attached release assets.

## Norming data and documentation

Norming data and supporting materials are available on the [OSF project page](https://osf.io/vurm5/).

The accompanying article reports two adult norming studies:

- **Study 1 (N = 1,261):** Evaluation of the AI-generated images.
- **Study 2 (N = 131):** Evaluation of photographs from an existing child-face database for comparison.

Ratings included perceived realness, age, racial group membership, femininity, masculinity, emotional expressions, niceness, and wealthiness. Consult the article for study methods and interpretation of the ratings. AI-generated stimuli may elicit social biases and should be selected with the goals of the study in mind.
