Stimuli and norming study

About the database

AI-generated face images and adult norming data for use in psychological research.

01 / Stimuli

Image database

The database contains 1,152 photorealistic, AI-generated images depicting children aged 3, 6, 10, and 15 years. The images vary in intended race/ethnicity, gender, age, and emotional expression.

Each age × gender × race/ethnicity category contains 18 images: 10 smiling, 4 angry, and 4 frowning. Each image depicts a different generated face; the database does not include multiple expressions of the same identity.

02 / Categories

Intended and perceived attributes

The image filters describe categories specified in the generation prompts. In the norming study, adult participants evaluated the images’ perceived realness, niceness, wealthiness, age, emotional expression, gender, and race/ethnicity. These ratings can be used to select and match stimuli for a study.

03 / Responses

Norming data

The website includes 1,297 anonymous response records containing 452,648 individual ratings. The response-record count does not establish the number of unique participants. Ratings from complete and partial responses are available, with completion status reported for each response.

04 / Statistics

Summary statistics

Each image has a reported mean, sample standard deviation (SD), and number of ratings (n) for each measure. Individual ratings are also available for inspection and analysis. Perceived age is reported in years; the remaining measures use a 1–7 scale. Recorded age ratings of zero are retained.

Using the norming data

  • The database contains more smiling than angry or frowning images. Account for the number of images in each category when comparing groups.
  • Norming ratings describe perceptions of AI-generated images. They do not measure attributes of real children or establish differences between demographic groups.
  • Response numbers are anonymous. Direct respondent identifiers and source-system metadata are excluded from the website data.
